# PDFsplitter

Нарезка многостраничного PDF на одностраничные файлы с шаблоном имени.

Два портативных exe — **каждый одним файлом**, Python внутри, ничего рядом ставить не нужно:

| Файл | Что делает |
|---|---|
| `dist\PDFsplitter.exe` | Консоль: режет сразу по маске |
| `dist\PDFsplitterGUI.exe` | Окно: маска → имена всех страниц → превью с зумом → правка имени → сохранение |

Собрать: `build.bat`. Убрать мусор сборки: `clean.bat` (удалит и `dist`, `.venv` не трогает).

## Маска имени

Постоянный текст плюс две подстановки:

- `{НАЧАЛО:ШАГ}` — номер: первый файл = НАЧАЛО, дальше плюс ШАГ (шаг можно не писать, тогда +1; шаг может быть отрицательным). `{216:+1}` → 216, 217, 218…
- `{DATE +формат}` — одна дата/время на весь запуск, формат как в strftime. `{DATE +%d_%m_%y}` → `01_09_26`

Неизвестные `{…}` остаются. Символы `<>:"/\|?*` становятся `_`. К имени добавляется `.pdf`, если его нет.

По умолчанию: `page_{1:+1}`.

Если даты на листах разные, пишите дату обычным текстом в маске и в GUI поправьте её у нужной страницы:

```
Акт о внедрении {216:+1} 27.06.2026
```

→ стр. 1 `Акт о внедрении 216 27.06.2026`, стр. 3 можно сменить на `Акт о внедрении 218 15.06.2026`.

Маску всегда берите в кавычки (`cmd` и PowerShell иначе ломают `{…}`).

## Консоль

```bat
PDFsplitter.exe "входной.pdf"
PDFsplitter.exe "входной.pdf" -d out -m "Акт о внедрении {216:+1} 27.06.2026"
```

- `-d` / `--out-dir` — папка (по умолчанию рядом с PDF)
- `-m` / `--mask` — маска имени

Из исходников:

```bat
.venv\Scripts\activate.bat
pip install -r requirements.txt
python split_pdf.py "входной.pdf" -d out -m "page_{1:+1}"
```

## GUI

```bat
PDFsplitterGUI.exe
PDFsplitterGUI.exe "входной.pdf"
```

Из исходников: `python split_gui.py` или `python split_gui.py "входной.pdf"`.

1. PDF, папка, маска → «Сформировать имена» (через «Обзор» PDF имена собираются сразу).
2. Слева список, справа превью. Внизу имя текущей страницы — его можно править по картинке.
3. «Сохранить и далее» (Enter в поле имени, Ctrl+S) или «Сохранить все».

В списке: пробел — как в шаблоне, `*` — поправили вручную, `✓` — сохранено.

Превью:

- `+` / `−` или Ctrl+колёсико — масштаб
- «По странице» — весь лист
- колёсико — вверх/вниз, Shift+колёсико — влево/вправо
- тянуть мышью или полосы прокрутки — сдвиг

Колёсико не листает страницы: для этого список и кнопки «Назад» / «Вперёд».

## Разработка

```bat
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

| Файл | Роль |
|---|---|
| `split_pdf.py` | Движок и консоль |
| `split_gui.py` | Окно |
| `requirements.txt` | pikepdf, pypdfium2, pyinstaller |
| `ТЗ.md` | Полное техническое задание |

В git не входят `.venv`, `dist`, `build` и рабочие `*.pdf`.
