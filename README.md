# PDFsplitter

Два портативных приложения:

| Файл | Что делает |
|---|---|
| `PDFsplitter.exe` | Консоль: режет PDF по маске имени |
| `PDFsplitterGUI.exe` | Окно: превью страницы, маска, правка имени, сохранение |

Маска имени — постоянный текст плюс две переменные: дата `{DATE +формат}` и нумерация `{начало:шаг}`.

## Консоль

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python split_pdf.py "входной.pdf" -d .\out -m "Акт о внедрении №{234:+1} {DATE +%d_%m_%y-%H%M%S}"
```

В PowerShell маску нужно брать в кавычки.

По умолчанию маска `page_{1:+1}`, каталог — рядом с исходным PDF.

## GUI

```powershell
python split_gui.py
python split_gui.py "входной.pdf"
```

Загрузить PDF → «Сформировать имена» по маске (сразу для всех страниц) → смотреть превью (приблизить/отдалить и подвигать документ) → при необходимости поправить имя текущей страницы (дату и т.д.) → «Сохранить и далее».

Пример маски: `Акт о внедрении {216:+1} 27.06.2026` даст 216, 217, 218… с одной датой. На третьем листе можно сменить на `Акт о внедрении 218 15.06.2026`.

## Сборка портативных exe

```bat
build.bat
```

Результат: `dist\PDFsplitter.exe` и `dist\PDFsplitterGUI.exe`. Их можно копировать без Python.

## Очистка мусора сборки

```bat
clean.bat
```

Удаляет `build/`, `dist/`, `.spec`, `__pycache__`. Папку `.venv` не трогает.
